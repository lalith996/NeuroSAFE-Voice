# Prepared dataset index

Run `scripts/prepare_datasets.py` from the project Python environment to regenerate the CSV files. All paths in the CSVs are relative to the project root.

- `utterance_manifest.csv`: one row per dataset, speaker, session, and utterance ID. It records the selected audio, original microphone paths, reference prompt, EMA and other modalities, duration, and task-specific eligibility.
- `quality_flags.csv`: all rows with missing files, fallback microphone selection, unusable prompts, or publisher-noted issues.
- `exclusion_log.csv`: each task exclusion with its reason. An utterance can be excluded from ASR scoring while remaining a candidate AAI pair.
- `torgo_aai_pair_candidates.csv`: TORGO audio and `.pos` files matched by speaker, session, and utterance ID.
- `torgo_aai_validation.csv`: AG500 `.pos` frame structure and head-microphone duration check for every candidate. The validator reads 12 sensors × 7 float32 values at 200 Hz and checks finite positions. It found 6,267 format/timing-verified head-microphone pairs, 600 array-only pairs needing an alignment method, and 291 head-audio timing mismatches.
- `torgo_aai_verified_pairs.csv`: the 6,267 format/timing-verified subset, including 2,095 dysarthric recordings. This is a data-readiness subset, not a guarantee that every sensor trace is physically clean. Regenerate both validation files with `scripts/validate_torgo_ema.py`.
- `torgo_sensor_audit.csv`: per-track channel flatness and position-step review flags for all 6,267 verified pairs. No row is excluded automatically. Regenerate with `scripts/audit_torgo_sensors.py`.
- `torgo_sensor_availability.csv`: channels that are usually flat within a speaker/session. This is an audit aid; derive any training-time mask within the training fold.
- `torgo_sensor_audit_summary.json`: flag definitions and counts. The prioritized review queue is in `reports/torgo_sensor_review_queue.csv`.
- `torgo_audio_audit.csv` and `torgo_audio_audit_summary.json`: 9,104 baseline recordings screened for very low average level and digital clipping. Flags require listening review; regenerate with `scripts/audit_torgo_audio.py`.
- `torgo_speaker_splits.csv`: fixed four-fold speaker-disjoint train/validation/test assignments. Each speaker is a test speaker in exactly one fold. Each test fold includes two speakers with dysarthria. The split is fixed before model training; it is not claimed to be severity-balanced.
- `mocha_utterance_splits.csv`: fixed split within each primary MOCHA speaker. `fsew0` has 400/30/30 train/validation/test recordings; `msak0` has 399/30/30 plus one publisher-noted corrupted recording excluded.
- `mocha_speaker_swap.csv`: two transfer checks that train on one primary speaker and test on the other as an unseen speaker. Validation remains within the training speaker because only two primary speakers are available.
- `mocha_aai_pairs.csv`: decoded primary-speaker pair inventory, including audio and EMA durations, original time gap, frame-presence fraction, and flags.
- `mocha_aai_decoded/<speaker>/<id>.npz`: 919 primary-speaker pairs. Each contains `audio_pcm16`, `sample_rate_hz`, `ema_times_seconds`, `ema_present`, `ema_coordinates`, and `ema_channel_names`. These are raw decoded measurements, not normalized training targets or forced frame alignments. Regenerate them with `scripts/prepare_mocha_aai.py`.
- `mocha_aai_feature_index.csv`, `mocha_aai_feature_config.json`, and `mocha_aai_features/`: 919 pairs converted to synchronized 100 Hz log-mel and 14-channel articulatory arrays over audio/EMA overlap. No normalization is applied at this stage; regenerate with `scripts/prepare_mocha_features.py`. The first ridge AAI model and its train-only normalization are in `data/results/mocha_ridge_aai/`.
- `torgo_sensor_map.csv`: publisher default coil identity. `torgo_publisher_note_match_audit.csv` records which publisher fault notes match uniquely and which remain ambiguous. Regenerate with `scripts/map_torgo_sensors.py`.
- `torgo_aai_feature_index.csv`, `torgo_aai_feature_config.json`, and `torgo_aai_features/`: aligned 100 Hz TORGO acoustic/position arrays for 6,267 pairs, with a validity mask for each target channel. Regenerate with `scripts/prepare_torgo_aai_features.py`.
- `torgo_oof_aai_index.csv`, `torgo_oof_aai_config.json`, and `torgo_oof_aai_features/`: 9,104 *predicted*, not measured, AAI sequences for ASR. Every speaker uses the model from its held-out fold. Regenerate with `scripts/export_oof_aai_features.py` after `scripts/compare_aai_transfer.py`.
- `torgo_oof_aai_cmvn_index.csv`, `torgo_oof_aai_cmvn_config.json`, and `torgo_oof_aai_features_cmvn/`: 9,104 predicted sequences from the retained per-recording-normalized ridge AAI model. These remain inferred audio features, not measured test-speaker EMA.
- `torgo_long_asr_splits.csv`: fixed long-recording ASR roles for four speaker-disjoint folds. The test portion has 187 unique 6–30-second recordings from eight dysarthric speakers. Their written prompts have `project_prompt_target` status. Regenerate only when intentionally replacing the frozen test set with `scripts/prepare_long_asr_review.py`.
- `manual_verified_transcripts.csv`: explicit clip-linked listening decisions imported from a completed review CSV. It currently has no reviewed rows.
- `torgo_long_scoring_targets.csv`: one scoring target per long test clip. Currently all 187 rows use the user-designated written prompts with `project_prompt_target` status. The same rows are exported as `data/exports/torgo_long_test_targets.csv`. Optional clip-specific corrections can be imported with `scripts/import_verified_transcripts.py`; saved ASR hypotheses can then be rescored with `scripts/rescore_long_asr.py`.

`maps0` is inventoried but excluded from primary MOCHA pretraining because it is supplementary and lacks per-utterance phoneme labels. The TORGO WER reference is an elicitation prompt rather than an independently verified verbatim transcript. Bracketed task directions, image prompts, `xxx`, missing prompts, and one corrupted prompt are excluded from ASR scoring. Bracketed pronunciation guidance after a target word is removed in `scoring_reference`.

The zero-shot Whisper baseline uses all eligible TORGO utterances without training. Its predictions and speaker-level WER are in `data/results/whisper_small_en_zero_shot/`; rerun or resume with `scripts/whisper_baseline.py`. Report this metric as **prompt-reference WER** and inspect prompt/audio mismatches before treating it as a gold-transcript result.

AG500 format references: [TORGO publisher README](https://catalog.ldc.upenn.edu/docs/LDC2012S02/README.txt) and [LDC TAPADM manual](https://catalog.ldc.upenn.edu/docs/LDC2012S02/Manual.pdf). The 200 Hz, 12 × 7 frame interpretation was checked against the head-microphone durations in the downloaded data. The first speaker-disjoint AAI comparison is in `data/results/torgo_mocha_transfer/` and summarized in `reports/torgo_mocha_transfer_round1.md`. Its modest correlation does not establish that inferred AAI helps ASR. The 600 array-only and 291 timing-mismatched pairs remain outside this experiment.
